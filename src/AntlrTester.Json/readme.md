# JsonArray

Testar att parsa en jsonliknande syntax som hanterar arrayer av strängar eller siffror, eller enkla objekt

## Objekt

```json
{
  "some":"property",
  "another":"property"
}
```

## String-array

```json
[ 'Hello', 'World' ]
```

## Number-array

```json
[ 1, 2, 501, 100 ]
```
